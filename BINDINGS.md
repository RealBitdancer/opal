# opal bindings and wrappers

Bindings expose opal to languages other than C. The known ones are listed here. If you
wrote one, or know of one that is missing, send a pull request and it will be added.

## Language bindings

| Name                                                    | Binding version | Language                     | License |
| :------------------------------------------------------ | :-------------: | :--------------------------: | :-----: |
| [opal-zig](https://github.com/RealBitdancer/opal-zig)   | 3.0.0-1         | [Zig](https://ziglang.org)   | MIT     |
| [opal-rust](https://github.com/RealBitdancer/opal-rust) | 3.0.0-1         | [Rust](https://www.rust-lang.org) | MIT     |

Binding versions are the bound opal release plus a packaging revision, so `3.0.0-1` is
the first binding release for opal `3.0.0`.

Bindings usually follow the naming convention `opal-{language}`.
